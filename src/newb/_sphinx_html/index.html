newb

A fresh AI agent reads only your package’s docs and tries to use the package — pytest-style. If it succeeds, your docs work. If it fails, your CI tells you which canonical question the docs couldn’t answer.

See the project README for the full architecture, security model, and installation matrix.

Five interfaces

Interface

How

CLI (primary)

newb <target> — see CLI reference

Python API

import newb; newb(".") — see Python API

MCP server

newb mcp start (pip install newb[mcp])

Skills

newb skills list — agent-facing _skills/ leaves

HTTP API

not applicable — newb has no web surface
